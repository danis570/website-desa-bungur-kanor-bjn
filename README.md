## 🚀 Instalasi

Clone repository

```bash
git clone https://github.com/username/website-desa-bungur.git
```

Masuk ke folder project

```bash
cd website-desa-bungur
```

Import database

```
Database/desa_bungur.sql
```

Sesuaikan konfigurasi database

```php
Config/database.php
```

Jalankan menggunakan

- XAMPP
- Laragon
- Apache
- PHP Built-in Server
